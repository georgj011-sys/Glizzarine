# Glizzarine

## Bauen lassen (wie bei Kaleido)
1. Neues Repository auf GitHub anlegen (Public).
2. "uploading an existing file" > ALLE Dateien aus diesem Ordner hineinziehen > Commit.
3. build.yml anklicken > Stift > im Namensfeld vor "build.yml" `.github/workflows/` tippen > Commit.
4. Reiter Actions > auf den grünen Haken warten (10–15 Minuten).
5. "Glizzarine-Windows" herunterladen, entpacken, "Glizzarine.vst3" nach C:\Program Files\Common Files\VST3 kopieren.

## KeyLab einrichten
1. KeyLab in den User-Modus schalten (damit es normale MIDI-Befehle sendet).
2. In Glizzarine auf die Seite "Setup" gehen und "Learn KeyLab" klicken.
3. Den Anweisungen folgen: Knob 1 drehen, Knob 2 drehen ... dann Fader 1 bis 8 bewegen.
4. Fertig. Die Belegung bleibt dauerhaft gespeichert, in jedem Projekt.
Einzelne Regler: Rechtsklick auf einen Regler > "MIDI learn" > am KeyLab bewegen.

## Seiten
Play: 8 Makros (1 = Brightness, 2 = Space), Basis-Regler, Klangwelle
Sound: 3 Oszillatoren, Filter, Hüllkurven, Cross FM, Ring Mod, Stimmenmodus
Motion: 2 LFOs, Vibrato und Aftertouch, Strange physics, 4 Mod-Slots
Arp: Muster, Rhythmus (auch selbst klicken), Mutation, Glitch, Hold, Lock, eigenes Tempo per Tap mit Taktart
Effects: Drive, Tape, Chorus/Ensemble, Phaser, Delay, Grains, Shimmer-Hall, Gate, Stereo
Setup: KeyLab-Steuerung
